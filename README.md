I am a software developer with extensive focus on **low-level scripting architectures, runtime manipulation, and script security analysis**. My work centers on building high-performance scripts, reverse-engineering virtualized protection layers, and developing robust automation pipelines.

* **Deobfuscation & VM Reversing:**
  * In-depth analysis of virtual machine obfuscators (e.g., *Prometheus*, *MoonSec*).
  * Opcode remapping, bytecode dumping, constant pool extraction, and control-flow flattening recovery.
  * Developing automated unpackers and syntax-tree restructurers.

* **Lua & Luau Engineering:**
  * Advanced runtime hooking, custom environment manipulation, and metatable virtualization.
  * High-efficiency scripting architectures designed for stability, low overhead, and high throughput.

* **Systems & Automation:**

  * Automated delivery systems, webhook orchestrations, and secure remote interfaces.
